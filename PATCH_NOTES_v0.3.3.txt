Konnaxion_Worlds World Manager bootstrap v0.3.3

Windows desktop bootstrap improvements:
- double-clicking Konnaxion_World_Manager.pyw now auto-runs SETUP_KONNAXION_WORLDS.ps1 when .venv is missing
- PowerShell 7 (pwsh) is preferred, with Windows PowerShell fallback
- setup is launched with -ExecutionPolicy Bypass and no separate console window
- setup stdout/stderr streams into the World Manager log and the Manager continues automatically after success
- setup now fails fast on native Python/pip/Django nonzero exit codes instead of silently continuing
- the Manager also discovers DATABASE_URL from the common sibling Konnaxion/backend/.env layout
- when no PostgreSQL URL is found, the Manager stays open and asks for it in the masked Database field instead of failing startup

No Django model migration is required.
